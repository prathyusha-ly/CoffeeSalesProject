# CoffeeSalesProject
“Developed an interactive Coffee Sales Dashboard in Excel using Pivot Tables, Slicers, Timeline, and advanced lookup functions. Analyzed sales trends, customer contributions, and regional performance to generate actionable insights. Showcases data visualization, reporting, and analytical thinking skills.”
#Features
## Time-based analysis
  Track total sales over months and years using an interactive timeline
## Product filtering
Filter data by:
- Roast Type (Dark, Medium, Light)
- Coffee Size
- Loyalty Card usage
- Sales by Country:
  Compare sales performance across different regions
- Top Customers Insight:
Identify highest contributing customers
- Dynamic Charts:
Automatically update based on slicer selections
